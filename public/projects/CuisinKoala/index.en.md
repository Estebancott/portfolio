## The Starting Point: The Fateful Question "What's for Dinner?"

We all know that moment: coming home from class or work, opening the fridge, and facing the interstellar void of inspiration. It is from this observation, and the desire to fight against food waste, that **Cuisin'Koala** was born, a mobile application that I developed as a team.

The idea was simple: create a kitchen companion that not only knows what I have in my fridge but also suggests intelligent recipes and helps me do my grocery shopping. A real project from A to Z, from code to database.

## The Tech Stack: A Modern Mobile Application 📱

To bring this project to life, we chose robust and modern technologies that allowed us to create a fluid and cross-platform user experience.

-   ![Angular Logo](https://upload.wikimedia.org/wikipedia/commons/thumb/c/cf/Angular_full_color_logo.svg/2048px-Angular_full_color_logo.svg.png#icon) **Angular**: A powerful framework for building a structured and maintainable web application.
-   ![Ionic Logo](https://upload.wikimedia.org/wikipedia/commons/thumb/d/d1/Ionic_Logo.svg/1200px-Ionic_Logo.svg.png#icon) **Ionic**: To transform our web application into a true native mobile application for iOS and Android, with access to the camera and phone features.
-   ![TypeScript Logo](https://upload.wikimedia.org/wikipedia/commons/thumb/4/4c/Typescript_logo_2020.svg/1200px-Typescript_logo_2020.svg.png#icon) **TypeScript**: For safer, cleaner, and easier-to-debug code.
-   ![Firebase Logo](https://upload.wikimedia.org/wikipedia/commons/thumb/3/37/Firebase_Logo.svg/1200px-Firebase_Logo.svg.png#icon) **Firebase**: I used Firebase for the entire backend part. ## Features That Change Lives 💡

What makes Cuisin'Koala truly special are its smart features that simplify life in the kitchen.

### 1. The Smart Fridge via OCR

No more chore of manually listing what remains in the fridge! I integrated a feature that uses the **phone camera** to scan a receipt. Thanks to **Optical Character Recognition (OCR)** technology, the application is able to read the receipt, identify the purchased products, and automatically add them to the virtual fridge inventory. It's a huge time saver!

### 2. Tailor-Made Recipes with the ChatGPT API

This is where the magic happens. Once the application knows the available ingredients, I use the **ChatGPT API** to generate creative and adapted recipe ideas. Just select a few ingredients, and the AI suggests a complete recipe, with preparation steps. It's the end of waste and the beginning of discovering new dishes.

![Example of AI-generated recipe](/projects/CuisinKoala/cuisinkoala-recipe.png "A carbonara pasta recipe generated from fridge ingredients.")

### 3. Grocery List Management and Nutritional Tracking

Of course, the application also allows managing grocery lists and tracking eating habits via weekly reports, for a healthier and better-organized diet.
